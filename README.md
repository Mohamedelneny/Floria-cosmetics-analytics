# Floria Cosmetics - E-Commerce Sales Analytics

## 📌 Project Overview
This project presents an interactive Power BI dashboard designed to analyze real-world sales performance and e-commerce transactions for **Floria Cosmetics**. The goal is to provide actionable business insights into revenue growth, product demand, and sales distribution.

## 🛠️ Tools & Technologies Used
* **Power BI**: Data modeling, DAX measures, visual reporting, and cloud publishing.
* **Power Query**: Data cleaning, handling missing values, and column transformations.
* **Excel / CSV**: Primary data source.

## 📊 Key Insights & Features
* **Sales Trends**: Tracked monthly and daily order volumes and revenue.
* **Product Performance**: Identified top-selling cosmetic products and best-performing categories.
* **Key Metrics**: Calculated Average Order Value (AOV) and total unit sales using custom DAX formulas.
